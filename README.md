# AI 探险家

一个根据培训课程范围重新设计的项目式 AI 学习系统。它不把“读完”当作完成，而是通过代码预测、参数实验、任务验收、解释挑战和掌握度评分收集真实学习证据。

## 运行

需要 Node.js 18 或更高版本，不需要安装第三方依赖。

```bash
npm run dev
```

浏览器访问 <http://localhost:4173>。

## 检查

```bash
npm run check
npm test
```

## 当前版本

- 11 个学习区域的完整课程地图
- Python 第一关：程序、值与变量
- Python 第二关：运算符、表达式与类型转换
- 数据驱动的多关卡引擎与每关独立进度
- 输出预测实验
- 变量状态工作台
- 表达式实验台与错误诊断
- 三题即时测验
- 费曼解释挑战
- 本地学习进度和四维掌握度
- L1–L5 五级考核路线（知识点、模块、框架、综合项目、面试官）
- 全知识面覆盖矩阵与统一完成标准
- GitHub Actions 持续集成

详细设计见 [docs/learning-design.md](docs/learning-design.md)，开发覆盖情况见 [docs/coverage-matrix.md](docs/coverage-matrix.md)。

## 内容原则

培训文件只用于确定知识范围。项目中的课程结构、文字、示例、交互和代码均重新组织与编写，不在仓库中提交原始培训文件。
