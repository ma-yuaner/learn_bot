# 数据结构专项学习路线

Python 的列表、字典和集合是现成容器；学会调用它们不等于理解数据结构。专项路线要求学习者能解释内部关系、手写核心操作、分析复杂度并在真实问题中选型。

## 每种结构的统一学习闭环

1. 用图形操作节点、索引或边，观察结构变化。
2. 使用 Python 容器完成应用任务。
3. 不依赖现成高级容器手写最小实现。
4. 给出查找、插入、删除和遍历的时间与空间复杂度。
5. 修复边界、空结构、断链、重复键和越界问题。
6. 对比替代结构并解释取舍。
7. 接受项目深挖和面试官连续追问。

## 模块路线

### DS01 复杂度与增长率

状态：✅ 已开放首版课程、操作计数实验、诊断题、解释评估与隐藏测试代码挑战。

- 输入规模、基本操作计数、最好/平均/最坏情况。
- O(1)、O(log n)、O(n)、O(n log n)、O(n²)。
- 时间与空间换取，摊还分析的直觉。
- 通过实际计数而不是只背结论判断复杂度。

产出：操作计数可视化器和带比较次数证据的线性查找。考核：解释为什么两个嵌套结构不一定都是 O(n²)。

### DS02 数组与动态数组

- 连续索引、随机访问、容量和扩容。
- 尾部追加、任意位置插入和元素搬移。
- Python list 与动态数组的关系。

产出：最小动态数组。考核：追踪扩容前后的容量、元素复制次数和摊还复杂度。

### DS03 链表

- 节点、引用、头尾指针、单向与双向链。
- 插入、删除、查找、反转和环检测。
- 空链、单节点、头尾删除等边界。

产出：任务链。考核：现场画出删除中间节点前后的引用变化。

### DS04 栈、队列与双端队列

- LIFO 与 FIFO。
- 调用栈、括号匹配、撤销、BFS 任务队列。
- 数组和链表实现的差异。

产出：探险指令撤销系统和任务调度队列。

### DS05 哈希表

- 哈希函数、桶、冲突、负载因子和扩容。
- 拉链法与开放寻址直觉。
- Python dict/set 的适用场景与键约束。

产出：物品索引。考核：解释为什么平均 O(1) 不代表永远 O(1)。

### DS06 树、二叉搜索树与遍历

- 根、父子、叶子、高度和子树。
- 前序、中序、后序和层序遍历。
- BST 插入、查找、删除与退化。

产出：技能树。考核：根据调用栈手工推演递归遍历。

### DS07 堆与优先队列

- 完全二叉树、数组表示、上浮与下沉。
- Top K、定时任务和优先级调度。

产出：紧急任务调度器。考核：逐步恢复堆性质并分析复杂度。

### DS08 图

- 顶点、边、有向/无向、权重、邻接表与邻接矩阵。
- DFS、BFS、连通性、拓扑排序和最短路直觉。

产出：探险地图路径系统。考核：比较 BFS 与 DFS 的状态、适用问题和空间代价。

## 框架考核

数据结构区域毕业时，学习者需要面对一个新需求，完成：

- 从约束中选择结构并排除至少两个替代方案。
- 画出内存关系或索引关系。
- 手写关键操作并通过隐藏边界测试。
- 给出复杂度推导，不只写最终符号。
- 注入一个结构损坏故障并定位。
- 回答面试官对扩容、冲突、递归深度和工程库选型的追问。
