# 数据结构专项学习路线

Python 的列表、字典和集合是现成容器；学会调用它们不等于理解数据结构。专项路线要求学习者能解释内部关系、手写核心操作、分析复杂度并在真实问题中选型。

## 每种结构的统一学习闭环

1. 用图形操作节点、索引或边，观察结构变化。
2. 使用 Python 容器完成应用任务。
3. 不依赖现成高级容器手写最小实现。
4. 给出查找、插入、删除和遍历的时间与空间复杂度。
5. 修复边界、空结构、断链、重复键和越界问题。
6. 对比替代结构并解释取舍。
7. 接受项目深挖和面试官连续追问。

## 模块路线

### DS01 复杂度与增长率

状态：✅ 已开放首版课程、操作计数实验、诊断题、解释评估与隐藏测试代码挑战。

- 输入规模、基本操作计数、最好/平均/最坏情况。
- O(1)、O(log n)、O(n)、O(n log n)、O(n²)。
- 时间与空间换取，摊还分析的直觉。
- 通过实际计数而不是只背结论判断复杂度。

产出：操作计数可视化器和带比较次数证据的线性查找。考核：解释为什么两个嵌套结构不一定都是 O(n²)。

### DS02 数组与动态数组

状态：✅ 已开放首版课程、容量与搬移实验、越界诊断、摊还解释评估及隐藏测试代码挑战。

- 连续索引、随机访问、容量和扩容。
- 尾部追加、任意位置插入和元素搬移。
- Python list 与动态数组的关系。

产出：最小动态数组与内存槽位工作台。考核：追踪扩容前后的容量、元素复制次数、插入搬移方向和摊还复杂度。

### DS03 链表

状态：✅ 已开放首版课程、插入删除/反转/成环实验、断链诊断、结构选型解释评估及隐藏测试代码挑战。

- 节点、引用、头尾指针、单向与双向链。
- 插入、删除、查找、反转和环检测。
- 空链、单节点、头尾删除等边界。

产出：链表指针调查台与索引链表反转器。考核：现场画出插入、删除、反转前后的引用变化，并用快慢指针证明环的存在。

### DS04 栈、调用栈与撤销

状态：✅ 已开放 LIFO、push/pop/peek、括号匹配、撤销、调用栈和空栈诊断。

产出：栈与撤销实验台、括号匹配器。考核：维护“尚未匹配左括号”不变量。

### DS05 队列与双端队列

状态：✅ 已开放 FIFO、头索引、deque、BFS 队列、有界容量和背压。

产出：队列与背压实验台。考核：解释为何高频 list.pop(0) 会造成线性搬移。

### DS06 哈希表

状态：✅ 已开放哈希函数、桶、冲突、负载因子、拉链法、开放寻址与扩容重散列。

产出：哈希冲突实验台和拉链分桶器。考核：解释平均 O(1) 的前提和最坏退化。

### DS07 二叉树与遍历

状态：✅ 已开放根/叶子/深度/高度、前中后序、层序、递归栈与数组表示。

产出：二叉树遍历观测台。考核：根据处理根的时机推导四种遍历。

### DS08 二叉搜索树

状态：✅ 已开放顺序不变量、查找/插入路径、三类删除、退化和平衡树动机。

产出：BST 路径实验台。考核：解释复杂度为何是 O(h) 而非无条件 O(log n)。

### DS09 堆与优先队列

状态：✅ 已开放完全二叉树数组模型、堆序、上浮/下沉、heapify、Top K、稳定优先级及代码验收。

产出：堆序修复实验台。考核：逐步恢复最小堆并解释为什么 heapify 是 O(n)。

### DS10 图搜索

状态：✅ 已开放有向/无向图、邻接表/矩阵、BFS、DFS、环与连通分量完整闭环。

产出：图搜索前沿实验台和 BFS 距离器。考核：证明 visited 的正确标记时机。

### DS11 排序

状态：✅ 已开放插入、选择、归并、快速排序的复杂度、稳定性、原地性与工程选型。

产出：排序轨迹比较台。考核：在重复键、近乎有序和内存受限场景中选择算法。

### DS12 二分查找

状态：✅ 已开放精确查找、lower/upper bound、闭区间/半开区间不变量和死循环诊断。

产出：二分区间审计台。考核：证明答案未被排除且区间每轮严格缩小。

### DS13 递归与分治

状态：✅ 已开放基例、规模缩小、调用栈、返回阶段、分治、重复子问题和栈深风险。

产出：递归栈帧实验台。考核：用终止性和归纳思路证明递归正确。

### DS14 回溯

状态：✅ 已开放决策树、选择/撤销、子集、排列、组合、剪枝正确性与指数复杂度。

产出：回溯决策树实验台。考核：证明剪枝不漏解并修复共享路径污染。

### DS15 动态规划

状态：✅ 已开放状态定义、转移、基例、计算顺序、记忆化、表格法和空间压缩。

产出：DP 状态表。考核：从最后一步推导转移，而不是背公式。

### DS16 工程选型与面试官关卡

状态：✅ 已开放操作矩阵、组合结构、公司阶段、全局工具选择、演进触发器和 L3 毕业要求。

产出：全局数据结构决策台。考核：完成跨结构设计，并应对复杂度、现场编码、选型和系统设计追问。

## 框架考核

数据结构区域毕业时，学习者需要面对一个新需求，完成：

- 从约束中选择结构并排除至少两个替代方案。
- 画出内存关系或索引关系。
- 手写关键操作并通过隐藏边界测试。
- 给出复杂度推导，不只写最终符号。
- 注入一个结构损坏故障并定位。
- 回答面试官对扩容、冲突、递归深度和工程库选型的追问。
