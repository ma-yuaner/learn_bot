# 学习平台产品路线

这份路线与课程内容并行推进。学习者可以持续使用稳定关卡，新增能力通过自动测试后再进入主线。

## P1：真实练习与自动验收

- 浏览器与服务端隔离的 Python 代码执行沙箱。
- CPU、内存、运行时间、文件和网络权限限制。
- 公开测试用于即时反馈，隐藏测试用于防止只迎合样例。
- 比较标准输出、函数返回值、文件结果和数据库状态。
- 错误信息分层：语法、类型、逻辑、边界、性能与工程结构。
- 项目提交验收：运行测试、生成诊断、保留修改历史。

验收标准：学习者提交的代码能够安全运行；系统能说明通过或失败的具体证据，且不能访问宿主机敏感资源。

## P2：记忆与个性化复习

- 错题本记录错误类型、提示次数、修改次数和最终解释。
- 间隔复习根据掌握度与时间安排重测。
- 相似题变式，避免记住固定答案。
- 前置知识图谱，用于定位真正的薄弱点。
- 学习卡点分析：阅读过久、连续猜错、边界遗漏、解释不完整。

验收标准：系统能解释“为什么现在推荐这道题”，并证明复习后无提示完成率提高。

## P3：学习档案与人工考核

- 账号、跨设备同步和数据导出。
- 保存代码作品、测试结果、框架图、解释记录和教师评语。
- 区分自动证据、人工证据与自我评价。
- 框架口试记录：问题、追问、提示、回答和复盘。
- 学习者可以查看和删除自己的数据。

验收标准：任何“已掌握”结论都能追溯到具体学习证据，而不是只有一个总分。

## P4：框架项目与面试官

- 每个区域完成一个可运行模块。
- 跨区域项目从环境、数据、模型延伸到服务和部署。
- 无提示从空目录重建最小系统。
- 面试官模式支持限时问答、连续追问、现场编码和系统设计。
- 根据回答动态追问，不把关键词匹配当成最终评价。
- 面试结束生成能力矩阵、证据、误区和复习任务。

验收标准：学习者能解释全链路、独立实现、修复注入故障，并在不同需求中说明技术取舍。

## P5：平台安全与可观测性

- 权限模型、密钥管理、审计日志和隐私脱敏。
- 内容版本、发布、灰度和回滚。
- 代码运行、评估服务和 AI 调用的链路追踪。
- 成本、延迟、失败率、提示依赖度和评估漂移监控。
- 对提示注入、越权工具调用和恶意代码进行红队测试。

验收标准：平台出现错误或质量下降时能够定位到具体版本和链路，并可安全回滚。
